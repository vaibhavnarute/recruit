# 🎯 Interview Scheduling System - Setup & Usage Guide

## 📋 Overview

Automated interview scheduling system with:
- ✅ **LangGraph** workflow orchestration
- ✅ **MCP** (Model Context Protocol) for optimization
- ✅ **Google Calendar API** for Meet link generation
- ✅ **Professional email** templates
- ✅ **MongoDB** persistence
- ✅ **Comprehensive error handling** (all errors return 200 status)

---

## 🏗️ Architecture

```
FastAPI Endpoint
    ↓
LangGraph Agent (Workflow Orchestration)
    ├── Node 1: Validate Inputs
    ├── Node 2: Create Google Meet Link (24h validity)
    ├── Node 3: Send Email Invitation
    ├── Node 4: Save to MongoDB
    └── Error Handler
    ↓
MCP Context Manager (Optimization)
    ├── Cache Google API responses
    ├── Track conversation context
    └── Optimize token usage
```

## 🚀 Quick Start

### Step 1: Install Dependencies

```bash
cd backend
pip install -r interview_scheduling_requirements.txt
```

### Step 2: Google Calendar API Setup

#### 2.1 Create Google Cloud Project

1. Go to: https://console.cloud.google.com/
2. Click "Create Project"
3. Name it: "AI Recruiter Interview System"
4. Click "Create"

#### 2.2 Enable Google Calendar API

1. In your project, go to "APIs & Services" → "Library"
2. Search for "Google Calendar API"
3. Click "Enable"

#### 2.3 Create OAuth Credentials

1. Go to "APIs & Services" → "Credentials"
2. Click "Create Credentials" → "OAuth client ID"
3. Application type: "Desktop app"
4. Name: "Interview Scheduler"
5. Click "Create"
6. Click "Download JSON"
7. Save as `google_credentials.json` in the `backend` folder

#### 2.4 First-Time Authentication

```bash
cd backend
python -c "from services.google_calendar_service import GoogleCalendarService; s = GoogleCalendarService(); s.authenticate()"
```

This will:
- Open browser for Google login
- Ask for Calendar API permissions
- Save refresh token to `google_token.json`
- Token valid for 24 hours

### Step 3: Environment Variables

Add to `.env` file in `backend` folder:

```bash
# Google Calendar (optional - credentials file is enough)
GOOGLE_CREDENTIALS_PATH=google_credentials.json
GOOGLE_TOKEN_PATH=google_token.json

# SMTP Email (required for sending emails)
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=your-app-password  # NOT your regular password!
SENDER_EMAIL=your-email@gmail.com

# MongoDB (should already be set)
MONGO_URI=mongodb+srv://...
MONGO_DB_NAME=resumate
```

#### How to Get Gmail App Password:

1. Go to: https://myaccount.google.com/security
2. Enable 2-Step Verification (if not already enabled)
3. Go to "App passwords"
4. Generate password for "Mail"
5. Use this password in `SMTP_PASSWORD`

### Step 4: Start the Server

```bash
cd backend
python main.py
```

Server will start at: http://localhost:8001

**Solution:**
```bash
# Download credentials from Google Cloud Console
# Save as: backend/google_credentials.json
```

### Issue: "SMTP authentication failed"

**Solution:**
```bash
# 1. Enable 2-Step Verification on Gmail
# 2. Generate App Password
# 3. Use App Password in SMTP_PASSWORD (not regular password)
```

### Issue: "MongoDB connection error"

**Solution:**
```bash
# Check MongoDB connection in .env
MONGO_URI=mongodb+srv://user:pass@cluster.mongodb.net/
MONGO_DB_NAME=resumate

# Test connection:
python -c "from db.mongo_client import MongoDBClient; client = MongoDBClient(); print('Connected!')"
```

### Issue: "Import Error: langgraph"

**Solution:**
```bash
pip install langgraph>=1.0.0
```

### Issue: "Meet link not generated"

**Possible Causes:**
1. Google Calendar API not enabled
2. OAuth credentials invalid
3. Token expired (re-authenticate)

**Solution:**
```bash
# Re-authenticate
python -c "from services.google_calendar_service import GoogleCalendarService; s = GoogleCalendarService(); s.authenticate()"
```

## 📊 Workflow Details

### LangGraph Nodes:

1. **validate_inputs**
   - Checks all required fields
   - Validates email formats
   - Ensures datetime is in future
   - Validates duration (15-180 minutes)

2. **create_meet_link**
   - Calls Google Calendar API
   - Creates calendar event with Meet link
   - Caches response (MCP optimization)
   - Token valid for 24 hours

3. **send_email**
   - Sends HTML email template
   - Includes Meet link and calendar invite
   - Professional formatting
   - Logs email in MongoDB

4. **save_to_mongodb**
   - Stores complete interview data
   - Includes all metadata
   - Tracks email/calendar status

5. **handle_error**
   - Catches errors at any step
   - Returns 200 status with error details
   - Logs errors for debugging

### MCP Integration:

1. **Context Manager**
   - Tracks conversation history
   - Compresses old messages
   - Saves tokens (reduces API costs)

2. **Cache Manager**
   - Caches Google API responses
   - 24-hour TTL
   - Avoids duplicate API calls

3. **Token Optimizer**
   - Optimizes LLM prompts
   - Reduces token usage
   - Maintains context quality

## 🔐 Security Notes

1. **Google Credentials**: Never commit `google_credentials.json` or `google_token.json` to git
2. **SMTP Password**: Use App Password, not regular Gmail password
3. **MongoDB URI**: Keep in `.env`, never commit
4. **API Keys**: Store in environment variables
